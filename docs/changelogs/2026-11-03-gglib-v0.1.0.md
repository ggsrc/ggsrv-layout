# feat: generate services on gglib v0.1.0

Tracking: alva-ai/mono-meta#1115, decision G15 = B (keep ggsrv-layout as
the service template and fix its sync). The sync fix itself is
ggsrc/public-ci#8; giving the Alva repositories' token read access to this
repository is a separate decision.

## 1. Current state

- Generated services used gglib from January (pseudo-versions), wpgx v0.4.4,
  dcache v0.4.0 and Go 1.24.7, and the gglib app API that v0.1.0 replaced
  (`NewApp`, `Start`, `WithOTEL`, `WithEnv`).
- The cron example used `gglib/resource/hatchet`, which gglib removed before
  v0.1.0 (decision G2).
- `AppName` defaulted to `demo3`, `.env.example` used names the code does
  not read (`DEBUG`, `REDIS_DB`, `GRPC_HOST`) and `ENV=dev`, which gglib
  treats as production.
- A generated project failed its own tests (the cache read the Redis address
  before the Redis container started) and its own lint (gci sections were
  `github.com/myorg` placeholders).

## 2. Behavior after this change

- `cmd/server/main.go` uses `app.New`, `Init` and `Run`: probes from the
  start, start-up retries while Postgres or Redis is down, ordered shutdown.
  Dependencies are registered before their users (resources stop in
  reverse order).
- gglib v0.1.0, wpgx v0.5.0, dcache v0.5.0, Go 1.27.3 (`go_version`).
- The cron example, its guide and the Hatchet containers are removed.
- `AppName` defaults to the project name; `.env.example` lists the variables
  the code reads.
- Generated projects pass `go mod tidy`, `go vet`, their golangci-lint
  configuration (gci sections `standard, default, localmodule`; `goconst`
  off in tests) and their tests.

## 3. Verification

Rendered with Jinja2 as cookiecutter does (project names `demo-svc`,
`another-svc` in org `acme`, `my-service`), proto code generated with buf,
then: `go build`, `go vet`, `golangci-lint run` v2.14.0 (0 issues in both
modules), `ENV=test go test ./...` with Postgres and Redis testcontainers
(pass), `go mod tidy -diff` (only the order of the local `api/go` require
depends on the project name).
